# react-native-libav

Hardware-accelerated libav (FFmpeg) video player for React Native Windows

## Installation


```sh
npm install react-native-libav
```


## Usage


```js
import { LibavView } from "react-native-libav";

// ...

<LibavView color="tomato" />
```
